# 分诊映射表（Triage Map）

> 用途：根据用户输入的业务四要素（产品/阶段/对手/痛点），匹配 1-3 个核心方法论 + 辅助方法论。
> 分诊顺序：先按**痛点**定位主域 → 再按**阶段**调整组合 → 最后按**品类/对手**微调。
> 方法论编号对应 methodology-index.md。

## 一、输入四要素（默认模式先收集，缺什么问什么）

| 要素 | 问题 | 选项 |
|------|------|------|
| 产品 | 卖什么？客单价？ | 自由文本 |
| 阶段 | 处于哪个阶段？ | A. 0→1 起盘 B. 1→10 增长 C. 成熟求变（转型/破局） |
| 对手 | 竞争对手是谁？竞争强度？ | 自由文本 |
| 痛点 | 最卡在哪？（可多选，但请挑最痛的1-2个） | 见下方九类 |

## 二、九类痛点 → 方法论映射

### 痛点1：没认知/没流量
- **核心域**：定位 + 传播内容
- **主选**：1.2 五类定位法 或 1.3 人货场（先定人）｜6.1 卖点穿透 S+F+F
- **辅选**：1.1 特劳特竞争定位（有强对手时）｜6.4 六平台模板（多平台分发）｜3.1 信号理论
- **组合路径**：定位（选战场）→ 卖点穿透（定话术）→ 六平台模板（分发）→ 信号理论（隐性塑造）

### 痛点2：卖不动/转化低
- **核心域**：消费心理
- **主选**：3.5 福格行为模型 B=MAP（诊断行为缺口）｜2.5 锚定效应 或 2.6 比例偏见（改造价格感知）
- **辅选**：3.6 确定性销售按钮｜3.7 即时满足营销｜3.1 信号理论｜6.2 场景化营销
- **组合路径**：福格模型（挂产扣诊断）→ 确定性/即时满足（改话术）→ 锚定（调价格感知）

### 痛点3：价格上不去/利润薄
- **核心域**：定价
- **主选**：2.1 提价10%利润翻倍（先算账）｜2.2 价格歧视/差异化定价 或 2.3 尾数定价
- **辅选**：2.4 支付痛感｜3.2 禀赋效应｜3.3 框架效应｜2.7 消费者定价4招｜5.7 反消费主义（高价长生命周期品）
- **组合路径**：提价算账（确认杠杆）→ 禀赋效应/框架效应（重塑感知）→ 价格歧视（差异化收割）→ 支付痛感（方案检查）

### 痛点4：增长停滞
- **核心域**：商业模式 + 战略
- **主选**：4.3 安索夫矩阵 或 4.4 商业画布（先体检）
- **辅选**：1.5 品类转换战略｜4.1 五种商业模式｜5.5 大单品策略
- **组合路径**：商业画布（全面体检）→ 安索夫矩阵（找增长点）→ 品类转换/大单品（落地）

### 痛点5：同质化内卷
- **核心域**：定位 + 战略
- **主选**：1.5 品类转换战略 或 1.7 产品定义三模型
- **辅选**：1.6 细分市场四标准（找新赛道）｜8.3 升维差异化（AI/科技）｜1.2 五类定位法（品类定位）
- **组合路径**：细分市场（找空白）→ 品类转换/产品定义（重新定义）→ 升维（建护城河）

### 痛点6：品牌无感/无记忆
- **核心域**：品牌资产
- **主选**：5.2 品牌情绪定位 或 5.4 品牌人设法
- **辅选**：3.1 信号理论｜3.3 框架效应｜5.3 品牌信任3D（信任品类）｜6.6 雷氏营销心法
- **组合路径**：品牌情绪/人设法（定调性）→ 信号理论（设计隐性钩子）→ 信任3D（建壁垒）

### 痛点7：自媒体起号
- **核心域**：创业增长
- **主选**：7.2 自媒体9步框架（整体系统）
- **辅选**：6.4 六平台模板（内容生产）｜7.3 30万粉丝六句话（心态）｜7.4 视频制作9问（制作）
- **组合路径**：9步框架（系统）→ 六平台模板（内容）→ 竞品跟踪（3+4+3）

### 痛点8：加盟/选品/投资决策
- **核心域**：决策思维
- **主选**：7.6 加盟/选品尽调（毛利净利）或 7.1 创业成功率两问
- **辅选**：2.8 机会成本思维｜7.5 信息偏差陷阱（防被误导）
- **组合路径**：创业两问（瓶颈匹配）→ 毛利净利（算账）→ 机会成本（对比决策）

### 痛点9：商业模式不清
- **核心域**：商业模式
- **主选**：4.4 商业画布（画现状）或 4.2 三大模式+假创业自检
- **辅选**：4.1 五种商业模式（找新模式）｜4.5 赚大钱vs赚小钱（选路线）
- **组合路径**：商业画布（画现状）→ 三大模式自检（验真伪）→ 五种模式（找新路）

## 四、单方法论 vs 组合方法论判定

- **单一问题**（"价格怎么定"→2.1-2.7 选一）→ 单个方法论 + 步骤 + 话术
- **复合问题**（"新产品怎么起盘"）→ 组合，按价值链顺序串联，每个环节 ≤2 个方法论
- **组合原则**：先定位后话术、先诊断后优化、先算账后行动
- 用户明确说"快速模式"或问题很小时：直接给出最相关的 1 个方法论 + 简短行动清单，不追问

## 七、联网搜索策略

1. **默认先出方案**：基于方法论索引直接给出方案，不等待搜索
2. **需要搜索的情形**：a) 用户要具体行业案例；b) 方案需最新市场数据；c) 用户问"XX品牌/行业怎么做"且方法论索引没有对应案例
3. **搜索范围**：经典理论原文（特劳特/波特/卡尼曼/奥格威）、行业案例、最新趋势数据
4. **搜索约束**：方法论的骨架以李三千内容为准，搜索只做补充印证与细节丰富，不得推翻方法论框架
